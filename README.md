

# 🗺️ خدمات - طرق - الرياض

مشروع تحليل مكاني تفاعلي لمدينة الرياض، بيحسب أقرب خدمة ليك وأقصر طريق ليها، وبيحلل تغطية الخدمات.

**لينك الموقع:** https://mawadrezk.github.io/riyadh-map-services/

## 🎯 فكرة المشروع
في الرياض فيه خدمات كتير، بس المستخدم مش عارف أقرب خدمة ليه فين، ولا أقصر طريق ليها، ولا الأحياء اللي مش متغطية بخدمات.

## 🛠️ الأدوات المستخدمة
- **Leaflet.js** - لعرض الخريطة
- **Leaflet Draw** - للرسم على الخريطة
- **Turf.js** - للتحليل المكاني (المسافة - المساحة - Buffer)
- **OSRM** - لحساب أقصر طريق على الطرق الحقيقية
- **GitHub Pages** - للنشر

## 📊 التحليلات الموجودة في المشروع

### 1. Buffer Analysis
بتعمل Buffer لأي شكل رسمته بمسافة انت بتحددها بالمتر.

### 2. Nearest Analysis - أقرب 3 خدمات
بياخد نقطة المستخدم، وبيحسب المسافة لكل خدمة بـ Turf، وبيرتبهم من الأقرب للأبعد، وبيعرض أقرب 3.

### 3. Routing - أقصر طريق
بيستخدم OSRM عشان يجيب أقصر طريق على الشوارع الحقيقية مش خط مستقيم، وبيحسب المسافة والوقت المتوقع.

### 4. Coverage Analysis - تحليل التغطية
بيعمل Buffer 2 كم حوالين كل خدمة، وأي منطقة بره الدواير دي تعتبر منطقة غير مخدومة ومحتاجة خدمة جديدة.
